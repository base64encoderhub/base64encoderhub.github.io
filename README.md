# Base64 Encoder

Encode and decode Base64 text, files and URLs in your browser. Free, fast and private — nothing you type ever leaves your device.

Free online tool site built for GitHub Pages. Static HTML, CSS and JavaScript only — no build step, no server, no tracking. Open `index.html` to start.

- Main tool: Base64 Encode / Decode (`tools/encode-decode.html`)
- 4 tools, 20 guides, 20 images.
